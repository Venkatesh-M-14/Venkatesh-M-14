# 📌 The Six Repositories to Pin (and Why)

Pinned repos are your above-the-fold real estate — recruiters rarely scroll past them. Order matters: left-to-right, top-to-bottom by impressiveness.

| # | Repository | Why it's pinned |
|---|---|---|
| 1 | **react-admin-dashboard** | The closest match to what companies actually hire React devs to build: data tables, charts, auth, roles. Shows enterprise patterns (React Query + Redux Toolkit + MUI) in one glance. |
| 2 | **react-ecommerce** | Instantly recognizable scope. Cart logic, checkout forms, and payment flow prove state-management and UX depth. Recruiters can evaluate it without reading code. |
| 3 | **react-hooks-library** | The only pin that proves *library author* skill: TypeScript API design, tests, docs, npm publishing, semantic releases. Separates you from CRUD-only developers. |
| 4 | **nextjs-dashboard** | Signals you're current — App Router, server components, streaming. Many job posts now say "React + Next.js"; this pin answers that question before it's asked. |
| 5 | **react-chat-app** | Real-time (websockets, presence, optimistic UI) is rare at the 3-year level. Great interview talking point and shows you can handle async complexity. |
| 6 | **portfolio-v2** | Meta-proof: the site recruiters visit is itself a polished open-source React project. Links your GitHub and portfolio into one loop. |

## Pinning strategy

- **Every pin needs:** a description with an emoji + live demo link, topics set, a banner/screenshot in the README, and a green CI badge. A pinned repo with a default description undoes the effort.
- **Balance the grid:** 3 apps (dashboard, ecommerce, chat) + 1 library + 1 Next.js + 1 portfolio = breadth without repetition. Don't pin two similar CRUD apps.
- **Knowledge repos** (`frontend-interview-preparation`, `javascript-algorithms`) earn stars but don't prove building skill — swap one in only if it gains real traction (100+ stars).
- **Rotate quarterly:** replace the weakest pin with whatever you shipped most recently and are proudest of.
